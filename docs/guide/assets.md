# Asset Extraction

Download images, fonts, and icons from target websites.

## Overview

Asset extraction downloads:
- **Images** - PNG, JPG, SVG, WebP, GIF
- **Fonts** - WOFF, WOFF2, TTF, OTF, EOT
- **Icons** - Favicons, SVG icons, icon fonts

## Basic Usage

```bash
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output
```

## Output Structure

```
output/
└── assets/
    ├── images/
    │   ├── hero-bg.jpg
    │   ├── logo.svg
    │   └── feature-1.png
    ├── fonts/
    │   ├── inter-regular.woff2
    │   └── inter-bold.woff2
    └── icons/
        ├── favicon.ico
        └── apple-touch-icon.png
```

## Image Extraction

### Sources

Images are extracted from:

| Source | Example |
|--------|---------|
| `<img src>` | `<img src="hero.jpg">` |
| CSS `background-image` | `background: url(bg.png)` |
| `<picture><source>` | Responsive images |
| `srcset` | Multiple resolutions |
| Inline SVG | `<svg>...</svg>` |

### Options

```bash
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output \
  --images-only          # Skip fonts and icons
  --min-size 1000        # Skip images < 1KB
  --max-size 5000000     # Skip images > 5MB
```

## Font Extraction

### Detected Formats

| Format | Extension | Support |
|--------|-----------|---------|
| WOFF2 | .woff2 | Modern browsers |
| WOFF | .woff | Wide support |
| TrueType | .ttf | Desktop/mobile |
| OpenType | .otf | Desktop |
| EOT | .eot | Legacy IE |

### Sources

Fonts extracted from:
- `@font-face` declarations
- Google Fonts links
- Adobe Fonts (Typekit)
- Self-hosted font files

### Generated Font CSS

```css
/* output/assets/fonts/fonts.css */
@font-face {
  font-family: 'Inter';
  src: url('./inter-regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
}

@font-face {
  font-family: 'Inter';
  src: url('./inter-bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
}
```

## Icon Extraction

### Favicon Detection

Extracts from:
```html
<link rel="icon" href="/favicon.ico">
<link rel="apple-touch-icon" href="/apple-icon.png">
<link rel="manifest" href="/manifest.json">
```

### SVG Icons

Inline SVGs are saved as separate files:

```html
<!-- Before -->
<button>
  <svg viewBox="0 0 24 24">
    <path d="M12 2L2 7l10 5..."/>
  </svg>
</button>

<!-- After -->
<button>
  <img src="assets/icons/icon-1.svg" alt="">
</button>
```

## URL Rewriting

Asset URLs in HTML/CSS are rewritten to local paths:

**HTML:**
```html
<!-- Before -->
<img src="https://example.com/images/hero.jpg">

<!-- After -->
<img src="assets/images/hero.jpg">
```

**CSS:**
```css
/* Before */
.hero {
  background: url('https://example.com/bg.png');
}

/* After */
.hero {
  background: url('assets/images/bg.png');
}
```

## Handling CDN Assets

### Common CDNs Supported

- Cloudflare CDN
- AWS CloudFront
- Imgix
- Cloudinary
- Unsplash
- Google Fonts

### CORS Issues

Some CDNs block direct downloads. Workarounds:

```bash
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output \
  --user-agent "Mozilla/5.0..."
```

## Advanced Options

### Filter by Type

```bash
# Images only
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output \
  --type images

# Fonts only
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output \
  --type fonts
```

### Exclude Patterns

```bash
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output \
  --exclude "analytics,tracking,ads"
```

### Concurrent Downloads

```bash
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output \
  --concurrency 5
```

## Troubleshooting

### 403 Forbidden

Site blocks automated downloads:
1. Add realistic user agent
2. Add referer header
3. Try with cookies

### Large Files Timeout

```bash
node src/core/extract-assets.js \
  --url "https://example.com" \
  --output ./output \
  --timeout 60000
```

### Missing Images

Some images may be:
- Lazy loaded (scroll first)
- Behind authentication
- Generated by JavaScript

Solution: Use `--wait` option with screenshot first.
