# Output Structure

Reference for all output files generated by Design Clone.

## Basic Clone Output

```
cloned-design/
├── desktop.png           # Desktop viewport screenshot
├── tablet.png            # Tablet viewport screenshot
├── mobile.png            # Mobile viewport screenshot
├── source.html           # Cleaned HTML (scripts removed)
├── source.css            # Filtered CSS (unused removed)
└── source-raw.css        # Original extracted CSS
```

## File Descriptions

### Screenshots

| File | Size | Description |
|------|------|-------------|
| `desktop.png` | 1920×1080 | Desktop viewport |
| `tablet.png` | 768×1024 | Tablet portrait |
| `mobile.png` | 375×812 | Mobile viewport |

Full-page screenshots may be taller depending on content.

### HTML Files

#### source.html

Cleaned HTML with:
- `<script>` tags removed
- Inline event handlers removed
- Data attributes preserved
- Structure maintained

#### pages/*.html (multi-page)

Individual page HTML with:
- Internal links rewritten
- Shared stylesheet linked
- Assets path updated

### CSS Files

#### source-raw.css

All CSS collected from:
- External stylesheets
- Inline `<style>` tags
- Computed styles (fallback)

#### source.css

Filtered CSS with:
- Unused selectors removed
- Duplicates removed
- @keyframes preserved
- @font-face preserved

#### styles.css (multi-page)

Merged CSS from all pages:
- Deduplicated rules
- Combined media queries
- Shared styles extracted

#### animations.css

Extracted animation rules:
```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

#### hover.css

Generated hover rules:
```css
.button:hover {
  background-color: #1d4ed8;
  transform: translateY(-2px);
}
```

### JSON Files

#### tokens.json

Design tokens extracted:
```json
{
  "colors": {
    "primary": "#2563eb",
    "secondary": "#64748b"
  },
  "typography": {
    "fontFamily": "Inter, sans-serif",
    "sizes": ["14px", "16px", "18px"]
  },
  "spacing": ["4px", "8px", "16px", "32px"]
}
```

#### animation-tokens.json

Animation metadata:
```json
{
  "keyframes": [
    {
      "name": "fadeIn",
      "frames": ["from", "to"],
      "properties": ["opacity"]
    }
  ],
  "transitions": [
    {
      "property": "all",
      "duration": "0.3s",
      "timing": "ease"
    }
  ]
}
```

#### hover-diff.json

Hover state differences:
```json
{
  "elements": [
    {
      "selector": ".button",
      "changes": {
        "backgroundColor": {
          "from": "#2563eb",
          "to": "#1d4ed8"
        }
      }
    }
  ]
}
```

#### manifest.json (multi-page)

Site metadata:
```json
{
  "domain": "example.com",
  "timestamp": "2024-01-15T10:30:00Z",
  "pages": [
    {
      "path": "/",
      "file": "index.html",
      "title": "Home"
    }
  ],
  "cssSize": {
    "original": 45000,
    "merged": 32000
  }
}
```

### Markdown Files

#### structure.md

AI analysis of page structure:
```markdown
# Page Structure Analysis

## Navigation
- Fixed header
- Logo left, menu right

## Hero Section
- Full-width background
- Centered text
```

### Asset Directories

#### assets/images/

Downloaded images:
- Original filenames preserved
- Duplicates deduplicated
- URL references updated

#### assets/fonts/

Downloaded fonts:
- WOFF2 preferred
- fonts.css with @font-face rules

#### assets/icons/

Favicon and icons:
- favicon.ico
- apple-touch-icon.png
- Other icons from manifest

### Hover States Directory

#### hover-states/

Screenshot pairs for each element:
- `hover-N-normal.png` - Before hover
- `hover-N-hover.png` - During hover
- `hover-diff.json` - All changes

## File Naming

### Single Page

Default: `cloned-design/`

Custom: `--output ./my-output`

### Multi-Page

Pattern: `cloned-designs/{timestamp}-{domain}/`

Example: `cloned-designs/20240115-103000-example-com/`

### Screenshots

Pattern: `{viewport}.png` or `{page}-{viewport}.png`

### Assets

Original filenames preserved when possible.

Conflicts resolved with suffix: `image.png`, `image-1.png`
